# Avouch

An agentic red-teaming and evaluation framework for LLM safety.

> 🚧 **Work in progress.** This project is under active development.

## About

Avouch uses a team of specialized AI agents to automatically probe large
language models for safety failures — jailbreaks, prompt injection,
hallucination, and more — then evaluates and reports the findings.

Currently in early development. Architecture and documentation coming soon.
